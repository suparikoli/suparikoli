## What I build

Integrations that connect ERPNext to the rest of a client's stack — the layer no off-the-shelf module covers.

| Repo | What it is |
| --- | --- |
| [polygin](https://github.com/suparikoli/polygin) | WhatsApp Business integration for ERPNext |
| [smartflo](https://github.com/suparikoli/smartflo) | Smartflo telephony integration for ERPNext |
| [ntfynext](https://github.com/suparikoli/ntfynext) | Notification layer built on ntfy |
| [medusync](https://github.com/suparikoli/medusync) | ERPNext ↔ Medusa.js sync |

Mithtech's product work — [Pulse](https://github.com/mithtech-is/Pulse) (agile project management on Frappe/ERPNext) and others — is built by the team and lives under [Mithtech-Bengaluru](https://github.com/Mithtech-Bengaluru) / [mithtech-is](https://github.com/mithtech-is).
